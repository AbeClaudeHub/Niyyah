# Book build pipeline

Turns the Markdown manuscript in [`../manuscript`](../manuscript) into a premium
digital book: a typeset **PDF** and a validated **EPUB 3**.

## Output (`dist/`)
- `The-Trader-and-the-Nafs.pdf` — 5.5×8.5″ typeset edition, embedded fonts,
  drop caps, running heads, page numbers, a linked table of contents with leaders.
- `The-Trader-and-the-Nafs.epub` — reflowable EPUB 3, embedded fonts, cover,
  nested navigation. Passes `epubcheck` with **0 errors / 0 warnings**.

## Design
- **Type:** EB Garamond (body) + Inter (labels/running heads), both OFL,
  embedded as static instances (`fonts/*.ttf`). Licenses in `fonts/_src/OFL-*.txt`.
- **Cover:** generated typographic cover (`assets/cover.png` / `.jpg`).
- **Palette:** ink `#22262c`, antique gold `#9c7c3c`, cream `#faf8f3`.

## Rebuild
```bash
pip install weasyprint markdown Pillow fonttools   # one-time deps
python3 build_pdf.py      # -> dist/...pdf
python3 build_epub.py     # -> dist/...epub
```
Fonts/cover are regenerated by the helper steps recorded in the repo history
(`fonts/` and `assets/` are committed, so the two build scripts are all you need).

## Files
- `parse.py` — parses the manuscript Markdown into a structured model.
- `build_pdf.py` — WeasyPrint (CSS Paged Media) → PDF.
- `build_epub.py` — hand-built EPUB 3 (zip + OPF + nav), fonts & licenses bundled.
